Política de Privacidad

Última actualización: 8 de septiembre de 2026

1. Objeto

Esta Política de Privacidad explica cómo AnalytIA Sports trata los datos personales necesarios para ofrecer sus servicios, mantener las cuentas de usuario, gestionar preferencias y notificaciones, prestar soporte y garantizar el correcto funcionamiento y seguridad de la aplicación.

AnalytIA Sports aplica el principio de minimización de datos y trata únicamente la información necesaria para las finalidades descritas en esta política.

2. Datos que tratamos

Dependiendo del uso que hagas de AnalytIA Sports, podemos tratar los siguientes datos:

  • Datos de cuenta: dirección de correo electrónico, nombre de usuario, identificador interno de usuario, permisos asociados a la cuenta y fechas relacionadas con su creación y actividad.
  • Datos de autenticación: información necesaria para iniciar y mantener la sesión o recuperar el acceso a la cuenta. Las contraseñas son gestionadas mediante Supabase Auth y no se almacenan en las tablas propias del backend de AnalytIA Sports.
  • Preferencias y funcionalidades: equipos o competiciones favoritas, alertas de partidos, idioma, orden y configuración de notificaciones.
  • Datos de notificaciones: token de Firebase Cloud Messaging, identificador técnico de instalación, plataforma, fechas de actividad y datos necesarios para gestionar y evitar envíos duplicados.
  • Datos técnicos: dirección IP, agente de usuario, información básica de las solicitudes, registros de funcionamiento, seguridad y errores generados por la infraestructura utilizada.
  • Datos de soporte: dirección de correo electrónico y contenido de las comunicaciones que nos envíes cuando solicites ayuda, ejerzas tus derechos o solicites la eliminación de tu cuenta.

No solicitamos durante el registro número de teléfono, domicilio, fecha de nacimiento, datos bancarios ni información de pago.

Actualmente AnalytIA Sports no incorpora publicidad, identificadores publicitarios, Firebase Analytics ni Firebase Crashlytics.

3. Finalidades del tratamiento

Los datos se utilizan para crear y gestionar tu cuenta, identificarte cuando utilizas el servicio, mantener tu sesión y permitir la recuperación del acceso.

También se utilizan para guardar tus favoritos, alertas, preferencias y demás configuraciones necesarias para proporcionar las funcionalidades que hayas solicitado.

Cuando utilizas las funciones de notificaciones, se tratan los datos técnicos necesarios para gestionar su envío mediante Firebase Cloud Messaging.

Determinados registros técnicos se utilizan para mantener la seguridad del servicio, diagnosticar errores, prevenir abusos, resolver incidencias y garantizar el funcionamiento de la infraestructura.

Cuando contactas con nosotros, utilizamos los datos proporcionados para atender tu consulta, incidencia, solicitud relacionada con privacidad o petición de eliminación de cuenta.

4. Legitimación

El tratamiento necesario para crear la cuenta y prestar las funcionalidades solicitadas se basa principalmente en la ejecución de la relación derivada del uso de AnalytIA Sports y en las actuaciones necesarias para proporcionar el servicio solicitado por el usuario.

Cuando una funcionalidad requiera una decisión voluntaria o un permiso específico del usuario, el tratamiento correspondiente podrá basarse en su consentimiento, que podrá retirarse cuando resulte aplicable.

Los tratamientos estrictamente necesarios para proteger la seguridad de AnalytIA Sports, prevenir abusos, diagnosticar incidencias o mantener la estabilidad del servicio podrán basarse en nuestro interés legítimo, siempre respetando los derechos y libertades de los usuarios.

Cuando sea necesario tratar o conservar información para cumplir una obligación establecida legalmente, el tratamiento se basará en el cumplimiento de dicha obligación legal.

5. Proveedores

AnalytIA Sports utiliza determinados proveedores tecnológicos para prestar el servicio.

Supabase se utiliza para la autenticación de usuarios y el almacenamiento de datos relacionados con las cuentas y las funcionalidades de la aplicación.

Railway se utiliza para alojar y ejecutar el backend de AnalytIA Sports. Como parte de su funcionamiento puede procesar solicitudes realizadas por la aplicación y generar determinados registros técnicos.

Google Firebase, mediante Firebase Cloud Messaging, proporciona la infraestructura utilizada para las notificaciones y puede tratar tokens, identificadores de instalación y otros datos técnicos necesarios para esta función.

Google/Gmail se utiliza actualmente como infraestructura para determinados correos electrónicos enviados desde nuestros sistemas.

AnalytIA Sports utiliza asimismo proveedores externos de información deportiva. En la arquitectura actual, las consultas a estos proveedores se realizan desde nuestros servidores y no se les transmiten directamente el correo electrónico, nombre de usuario, token de notificaciones o credenciales de los usuarios.

AnalytIA Sports no vende los datos personales de sus usuarios.

6. Transferencias internacionales

Algunos de los proveedores tecnológicos utilizados por AnalytIA Sports pertenecen a grupos internacionales o pueden utilizar infraestructura situada fuera del Espacio Económico Europeo.

Cuando el tratamiento implique una transferencia internacional de datos personales, se utilizarán los mecanismos y garantías previstos en la normativa aplicable, como decisiones de adecuación o garantías contractuales apropiadas, cuando correspondan.

Puedes solicitar más información sobre las garantías aplicables escribiendo a nuestro correo de contacto.

7. Conservación de los datos

Los datos directamente vinculados a una cuenta se conservarán mientras esta permanezca activa y sean necesarios para prestar AnalytIA Sports.

Cuando se elimine una cuenta, los datos asociados que ya no sean necesarios se eliminarán de los sistemas activos de AnalytIA Sports.

Determinados registros técnicos, copias de seguridad, registros de seguridad o comunicaciones podrán conservarse durante periodos adicionales cuando resulte necesario por motivos técnicos, para resolver incidencias, cumplir obligaciones legales, prevenir abusos o atender posibles responsabilidades.

Los periodos concretos pueden depender también de los ciclos de conservación aplicados por los proveedores tecnológicos utilizados.

Los datos se eliminarán, anonimizarán o dejarán de mantenerse cuando ya no sean necesarios para las finalidades que justificaron su conservación.

8. Eliminación de cuenta

Puedes solicitar la eliminación de tu cuenta directamente desde AnalytIA Sports.

También dispones de un procedimiento externo de eliminación de cuenta en:

analytiasports.es/delete-account.html

La eliminación de la cuenta supone la eliminación del usuario de autenticación y de los principales datos vinculados a la cuenta en nuestra base de datos, incluidos el perfil, favoritos, alertas, dispositivos registrados y registros de notificaciones asociados.

La eliminación de la cuenta no implica necesariamente la desaparición instantánea de cualquier dato que pueda permanecer temporalmente en copias de seguridad, registros técnicos, registros de seguridad, sistemas de proveedores o comunicaciones previamente realizadas.

Cuando exista una necesidad legítima de conservación temporal, dichos datos dejarán de utilizarse para las finalidades ordinarias asociadas a la cuenta y serán eliminados o dejarán de ser identificables cuando corresponda.

9. Almacenamiento local

AnalytIA Sports puede almacenar localmente determinadas preferencias necesarias para el funcionamiento de la aplicación, como idioma, orden, configuración de notificaciones u otras opciones seleccionadas por el usuario.

Algunos de estos datos pueden permanecer en el dispositivo después de eliminar una cuenta hasta que se eliminen los datos locales de la aplicación o esta sea desinstalada.

Este almacenamiento no se utiliza con fines publicitarios.

10. Derechos

Puedes ejercer, cuando resulten aplicables, tus derechos de acceso, rectificación, supresión, limitación del tratamiento, oposición, portabilidad y retirada del consentimiento.

Para ejercerlos puedes escribir a:

soporte@analytiasports.es

Cuando resulte necesario podremos solicitar información razonable para comprobar tu identidad y evitar accesos, modificaciones o eliminaciones no autorizadas.

También tienes derecho a presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD) si consideras que el tratamiento de tus datos personales no cumple la normativa aplicable.

11. Sistemas automatizados

AnalytIA Sports utiliza sistemas automatizados para analizar información deportiva y generar estadísticas, probabilidades, indicadores y pronósticos relacionados con eventos deportivos.

Estos sistemas analizan información deportiva y no toman decisiones automatizadas sobre los usuarios que produzcan efectos jurídicos o les afecten de forma significativamente similar.

Las preferencias, favoritos o alertas seleccionadas por el usuario se utilizan para proporcionar las funcionalidades correspondientes y no para adoptar decisiones jurídicas o equivalentes sobre él.

12. Seguridad

AnalytIA Sports aplica medidas técnicas y organizativas destinadas a proteger los datos personales frente a accesos no autorizados, pérdida, alteración o divulgación indebida.

La autenticación se gestiona mediante infraestructura especializada y las comunicaciones con los servicios utilizados se realizan mediante mecanismos de conexión segura cuando corresponde.

No obstante, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

13. Menores de edad

AnalytIA Sports está dirigida a usuarios de 18 años o más.

Las personas menores de 18 años no deben crear una cuenta en AnalytIA Sports.

Si tenemos conocimiento de que una cuenta pertenece a una persona menor de 18 años, podremos adoptar las medidas necesarias para eliminar la cuenta y los datos personales asociados cuando corresponda.

15. Actualizaciones

Esta Política de Privacidad podrá actualizarse cuando cambien las funcionalidades de AnalytIA Sports, se incorporen nuevos proveedores, se modifique el tratamiento de datos o resulte necesario adaptarla a cambios técnicos o normativos.

Cuando los cambios sean relevantes para los usuarios, podremos comunicarlos mediante la aplicación o a través de otros medios adecuados.
