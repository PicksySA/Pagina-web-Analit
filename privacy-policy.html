Política de privacidad

Esta política explica cómo AnalytIA Sports puede tratar datos personales y técnicos necesarios para prestar el servicio.

Responsable del servicio

El responsable legal definitivo del servicio debe completarse antes de publicar la app en Google Play. No se muestran datos fiscales o societarios hasta que estén confirmados.

Datos que se pueden tratar

AnalytIA Sports puede tratar los siguientes datos:

  • Email asociado a la cuenta.
  • Nombre o datos de perfil si el usuario los proporciona.
  • Identificador de usuario.
  • Plan de usuario si aplica.
  • Datos técnicos necesarios para funcionamiento, seguridad o diagnóstico.
  • Datos deportivos consultados dentro de la app, solo si se registran en logs técnicos o analítica operativa.

Finalidad del tratamiento

Los datos se utilizan para crear y gestionar cuentas, permitir el acceso a la app, mostrar información deportiva, mantener la seguridad del servicio, resolver incidencias y prestar soporte.

Creación y gestión de cuenta

La app puede utilizar email, identificador de usuario y datos básicos de perfil para permitir el registro, inicio de sesión y mantenimiento de la cuenta.

Autenticación y recuperación de contraseña

La autenticación y la recuperación de contraseña pueden gestionarse mediante proveedores externos especializados, como Supabase, para proteger el acceso del usuario.

Datos técnicos mínimos

Se pueden tratar datos técnicos mínimos, como eventos de seguridad, errores, registros operativos o información necesaria para diagnosticar incidencias y mantener el servicio disponible.

Proveedores externos

AnalytIA Sports puede apoyarse en proveedores externos como:

  • Supabase para autenticación y base de datos.
  • Proveedor de hosting o backend cuando se despliegue.
  • Proveedor de datos deportivos/API cuando corresponda.
  • Google Play para la distribución de la app.

Conservación de datos

Los datos se conservan mientras sean necesarios para prestar el servicio, mantener la cuenta, cumplir obligaciones legales o proteger la seguridad del sistema.

Eliminación de cuenta

El usuario puede solicitar la eliminación de su cuenta desde la app o mediante la página de eliminación de cuenta. Se eliminarán los datos asociados salvo aquellos que deban conservarse por motivos legales, seguridad, prevención de fraude o cumplimiento normativo.

Seguridad

Se aplican medidas técnicas y organizativas razonables para proteger la información frente a accesos no autorizados, pérdida o uso indebido.

Derechos del usuario

El usuario puede solicitar información, rectificación o eliminación de sus datos, así como plantear consultas sobre privacidad escribiendo al email de contacto.

Contacto

Para consultas de privacidad, escribe a soporte@analytiasports.com.
